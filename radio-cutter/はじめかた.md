# はじめかた（パソコンに詳しくない方向け）

このページは「ターミナルを触ったことがない」前提で書いています。
技術的な細かい説明は [README.md](README.md) にあります。

---

## 0. いまどこに何があるか

**このプログラムは、まだあなたの Mac の中にはありません。**

置いてあるのは GitHub というインターネット上の保管場所です。

```
リポジトリ : kensei329/Chikuho.Shimin.Univ
ブランチ   : claude/new-session-4sd1c9
フォルダ   : radio-cutter/
```

これから、それを自分の Mac に持ってきて使えるようにします。
**この準備は最初の1回だけ**です。2回目からは動画を渡すだけになります。

---

## 1. ターミナルを開く

1. キーボードで `command` + `スペース` を押す
2. 出てきた枠に `ターミナル` と打って `return`

黒い（または白い）窓が開きます。ここに文字を打ち込んで使います。

このページに出てくる枠の中身は、**そのままコピーして貼り付けて `return`** で大丈夫です。
`$` は「ここから打ってください」という印なので、`$` 自体は入力しません。

---

## 2. 下ごしらえ（Homebrew）

Homebrew は「Mac に道具を入れるための道具」です。まず入っているか確かめます。

```
$ brew --version
```

`Homebrew 4.x.x` のように出れば入っています。**次の 3 に進んでください。**

`command not found` と出たら入っていないので、[brew.sh](https://brew.sh) の
トップページにあるコマンドをコピーして貼り付けて実行します（10分ほどかかります）。

---

## 3. 必要な道具を入れる

```
$ brew install ffmpeg python@3.12 git
```

- **ffmpeg** … 動画を切ったり繋いだりする本体
- **python** … このプログラムを動かす土台（Mac に最初から入っているものは古すぎます）
- **git** … 保管場所からコードを持ってくる道具

5〜15分ほどかかります。途中で止まったように見えても待ってください。

続けて Claude Code を入れます。概要欄とタイトルを考えさせるのに使います。

```
$ curl -fsSL https://claude.ai/install.sh | bash
```

入ったか確認します。

```
$ claude --version
```

`2.x.x (Claude Code)` のように出れば大丈夫です。

---

## 4. コードを持ってくる

書類フォルダの中に置くことにします。

```
$ cd ~/Documents
$ git clone -b claude/new-session-4sd1c9 https://github.com/kensei329/Chikuho.Shimin.Univ.git
$ cd Chikuho.Shimin.Univ/radio-cutter
```

これで `~/Documents/Chikuho.Shimin.Univ/radio-cutter` にファイル一式が入りました。

---

## 5. インストール

```
$ python3.12 -m pip install -e '.[llm,asr]'
```

引用符（`'`）まで含めてコピーしてください。

> **お使いの Mac が Intel の場合**（M1・M2・M3・M4 ではない場合）は、
> 代わりにこちらを実行してください。
> ```
> $ python3.12 -m pip install -e '.[llm,asr-x]'
> ```
> 画面左上のリンゴマーク →「このMacについて」で確認できます。
> 「チップ Apple M…」と書いてあれば Apple Silicon です。

---

## 6. Claude Code にログインする

**API キーの発行や、別料金の契約は要りません。** すでにお使いの Claude の
アカウント（Pro / Max など）にログインするだけです。

```
$ claude
```

初回はブラウザが開くので、いつも使っている Claude のアカウントでログインしてください。
終わったら `/exit` と打つか `control` + `D` を2回押して抜けます。

一度ログインすれば、次からは聞かれません。

> **以前の手順で `ANTHROPIC_API_KEY` を設定した方へ**
>
> 古い手順では API キーを設定するようご案内していました。いまは不要です。
> それどころか、設定が残っているとログインではなくキーのほうが使われて、
> 別料金がかかってしまいます。次で確認して、出てきたら消してください。
>
> ```
> $ grep ANTHROPIC_API_KEY ~/.zshrc
> ```
>
> 行が表示されたら、`open -e ~/.zshrc` でファイルを開き、
> `export ANTHROPIC_API_KEY=...` の行を丸ごと削除して保存し、
> ターミナルを開き直してください。

# 動かす

## 動画の形式について

**iPhone で撮った `.MOV` は、そのまま渡して大丈夫です。変換は要りません。**

- 「高効率」設定（HEVC）でも「互換性優先」設定（H.264）でもどちらでも通ります
- 大文字の `.MOV` でも大丈夫です
- ファイル名に日本語やスペースが入っていても大丈夫です
- 縦向きで撮った動画は、縦のまま書き出されます

出来上がる動画は必ず `.mp4` になります。YouTube はこちらを好みます。

## ファイルの場所を打ち込むコツ

長いファイル名を手で打つ必要はありません。

1. ターミナルに `radio-cutter run ` まで打つ（**最後に半角スペースを1つ入れる**）
2. Finder から動画ファイルを**ターミナルの窓にドラッグ＆ドロップ**する
3. 場所が自動で入るので、そのまま `return`

## 実際の流れ

動画を置いてあるフォルダに移動してから始めます。

```
$ cd ~/Movies
```

### 1回目 ― まず切り口だけ確かめる

```
$ radio-cutter run 収録.MOV --dry-run
```

`--dry-run` を付けると、**動画は書き出さずに「どこで切るか」だけを決めます。**
60分の動画を書き出すのは時間がかかるので、先にここで確認します。

初回は文字起こしの部品（約3GB）を自動で取りに行くので、10〜30分ほどかかります。
2回目からは同じ動画なら文字起こしをやり直しません。

### 2回目 ― 切り口を目で見る

`~/Movies/out/収録/` の中に `preview` というフォルダができています。
その中の短い動画を Finder からダブルクリックして見てください。

| ファイル | 何が見えるか |
|---|---|
| `cut_A.mp4` | 本編の始まり（「このチャンネルは」の直前） |
| `cut_B.mp4` | エンディングの始まり（「ということで」の直前） |
| `highlight_in.mp4` | 冒頭フックの始まり |
| `highlight_out.mp4` | 冒頭フックの終わり |

**言葉の頭が切れていなければ成功です。**

### 3回目 ― 書き出す

```
$ radio-cutter run 収録.MOV --from-step 7
```

`~/Movies/out/収録/` に一式が出ます。

| ファイル | 中身 |
|---|---|
| `final.mp4` | YouTube にアップロードする完成版 |
| `description.txt` | 概要欄。中身を全部コピーして貼るだけ |
| `titles.md` | タイトル候補30個。気に入ったものを選ぶ |
| `decisions.json` | 何をどう判断したかの記録 |

# うまくいかないとき

## 「アンカーが見つかりません」と出て止まった

決まり文句が聞き取れなかったときです。**勝手に変な場所で切らずに止まる**ようにしてあります。

画面に「惜しかった候補」とその前後の言葉が出ています。実際に何と言っているかを見て、
`config/ai-radio.json` の `phrase` をその言い方に合わせてください。

## 言葉の頭が少し切れている／余計な音が入る

無音の判定を調整します。

```
録音の音が大きめ・雑音が多い場合
$ radio-cutter run 収録.MOV --from-step 4 --silence-db=-28

静かすぎる場合
$ radio-cutter run 収録.MOV --from-step 4 --silence-db=-38
```

`--from-step 4` は「切り口を決め直すところからやり直す」という意味です。
文字起こしはやり直さないので、すぐ終わります。

## 「Claude Code が見つかりません」と出た

概要欄とタイトルを作る段階で出ます。動画の切り出し自体は終わっているので、
Claude Code を入れ直してログインし、`--from-step 5` でその先だけやり直せます。

```
$ claude --version     # 入っているか確認
$ claude               # ログインし直す（/exit で抜ける）
$ radio-cutter run 収録.MOV --from-step 5
```

## 途中で失敗した／やり直したい

作りかけのファイルは消えません。同じコマンドをもう一度実行すれば、
できているところは飛ばして続きから進みます。

## それでも分からないとき

`out/<動画の名前>/decisions.json` に、何をどう判断したかが全部残っています。
このファイルを見せてもらえれば、何が起きたか追えます。
