# 活動ページの写真

`katsudo.html`（活動）のリールに出る写真を、ここに置きます。

## 置くファイル

次の名前で置いてください。ファイル名はHTML側に書いてあるので、変えると出なくなります。

| ファイル名 | 誰の写真か | カード |
|---|---|---|
| `01-murata.jpg` | 村田喜代子さん（作家） | GUEST 01 |
| `02-nakamura.jpg` | 中村哲さん（医師） | GUEST 02 |
| `03-imai.jpg` | 今井通子さん（登山家・医師） | GUEST 03 |
| `04-jaxa.jpg` | JAXA（宇宙開発） | GUEST 04 |

拡張子まで含めて一致させてください。`.jpeg` や `.JPG` では読み込まれません。
別の拡張子で置きたいときは、`katsudo.html` の該当する `<img src="...">` も直してください。

## 大きさ

**長辺 1200px 前後、1枚 500KB 以下**を目安にしてください。

会員は70代が中心で、通信環境もまちまちです。元データのまま数MBの写真を4枚並べると、
リールが開くまで待たされます。カードは画面いっぱいに切り抜いて表示するので、
1200pxあれば足ります。

縦長（3:4 くらい）がいちばん収まりよく出ます。

## 顔の位置

写真は `object-fit: cover` で切り抜かれます。顔が切れるときは、`katsudo.html` の
その `<img>` の `style="object-position: 横% 縦%"` を直してください。
数字を小さくすると、切り抜く位置が左（上）へ寄ります。

いま入れてある値は次のとおりです。

| ファイル | object-position |
|---|---|
| `01-murata.jpg` | `50% 26%` |
| `02-nakamura.jpg` | `50% 22%` |
| `03-imai.jpg` | `34% 30%` |
| `04-jaxa.jpg` | `50% 42%` |

## 写真が無いときの見え方

**置かなくても崩れません。**読み込みに失敗すると `.card__photo` に `is-blank` が付き、
カードごとに決めた色の面に切り替わります（`css/reel.css` の末尾）。
写真が揃うまでは、その状態で公開しても成立します。

## 権利

写真の権利は、それぞれの権利者に帰属します。JAXAの写真には提供元の表示が必要です
（カードの解説の末尾に「写真提供：JAXA」と入れてあります）。
ご本人やご遺族、所属先の許諾が要るものは、確認のうえで置いてください。
