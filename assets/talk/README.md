# 活動ページの写真

`katsudo.html`（活動）のリールに出る写真を、ここに置きます。

## 置くファイル

次の名前で置いてください。ファイル名はHTML側に書いてあるので、変えると出なくなります。

| ファイル名 | 誰の写真か | 寸法 | 容量 |
|---|---|---|---|
| `01-murata.webp` | 村田喜代子さん（作家） | 347×521 | 37KB |
| `02-nakamura.webp` | 中村哲さん（医師） | 676×896 | 54KB |
| `03-imai.webp` | 今井通子さん（登山家・医師） | 900×1200 | 146KB |
| `04-jaxa.webp` | JAXA（宇宙開発） | 900×1200 | 124KB |

**形式は WebP に揃えています。**受け取ったのは PNG 1枚と WebP 3枚でしたが、
PNG のまま置くと写真1枚で 317KB かかっていました（WebP にして 37KB）。
差し替えるときも WebP を推奨します。JPEG で置く場合は、`katsudo.html` の
該当する `<img src="...">` の拡張子も直してください。

**村田さんの1枚だけ 347×521 と小さく、拡大して表示されます。**
カードは画面いっぱいに引き伸ばすため、端末によっては輪郭がやや甘く見えます。
長辺 900px 以上の版が手に入ったら、差し替えてください。

## 大きさ

**長辺 1200px 前後、1枚 500KB 以下**を目安にしてください。

会員は70代が中心で、通信環境もまちまちです。元データのまま数MBの写真を4枚並べると、
リールが開くまで待たされます。カードは画面いっぱいに切り抜いて表示するので、
1200pxあれば足ります。

縦長（3:4 くらい）がいちばん収まりよく出ます。

## 顔の位置

写真は `object-fit: cover` で切り抜かれます。顔が切れるときは、`katsudo.html` の
その `<img>` の `style="object-position: 横% 縦%"` を直してください。
数字を小さくすると、切り抜く位置が左（上）へ寄ります。

いま入れてある値は次のとおりです。

| ファイル | object-position |
|---|---|
| `01-murata.webp` | `48% 26%` |
| `02-nakamura.webp` | `40% 22%` |
| `03-imai.webp` | `12% 30%` |
| `04-jaxa.webp` | `50% 42%` |

**いまの4枚では、縦の値は効きません。**どれも写真のほうがカードより横長なので、
高さに合わせて拡大され、切れるのは左右だけだからです。顔の高さを変えたいときは、
写真そのものを切り直してください。

なお、カードの文字は下に沈めてあります（`css/reel.css` の末尾で
`.card__main { justify-content: flex-end; }`）。もとは縦中央で、
どの写真も顔のちょうど上に見出しが重なっていました。

## 写真が無いときの見え方

**置かなくても崩れません。**読み込みに失敗すると `.card__photo` に `is-blank` が付き、
カードごとに決めた色の面に切り替わります（`css/reel.css` の末尾）。

写真が届くまでのあいだは、20px 幅まで潰した写真を data URI にしたものを
`background-image` に敷いています（`katsudo.html` の `.card__photo` の
`style` にある base64）。写真を差し替えたら、この下地も作り直してください。
無くても動きますが、読み込み中に白地へ文字だけが浮きます。

## 権利

写真の権利は、それぞれの権利者に帰属します。JAXAの写真には提供元の表示が必要です
（カードの解説の末尾に「写真提供：JAXA」と入れてあります）。
ご本人やご遺族、所属先の許諾が要るものは、確認のうえで置いてください。

JAXA の写真には提供元の表示が焼き込まれていますが、カードの切り抜きで下端が
隠れます。そのため、カードの本文にも「写真提供：JAXA」と出しています。
