# 分科会の写真

四つの分科会のストーリー（`kai-*.html`）を開いた、**1枚目に出る写真**をここに置きます。

## 置くファイル

次の名前で置いてください。ファイル名はHTML側に書いてあるので、変えると出なくなります。

| ファイル名 | どの会か | 寸法 | 容量 |
|---|---|---|---|
| `kyoyo.webp` | 教養講座（第1分科会） | 900×1600 | 156KB |
| `healthy.webp` | ヘルシーエイジング（第2分科会） | 900×1600 | 85KB |
| `teizan.webp` | 低山に登ろう（第3分科会） | 900×1600 | 237KB |
| `history.webp` | 歴史を辿る会（第4分科会） | 900×1600 | 159KB |

## 分科会の選び口に敷く、横長の版

`bunkakai.html`（四つの札）にも、同じ写真をうっすら敷いています。札は横長なので、
真ん中あたりの帯を切り出した別の版を置いています。

| ファイル名 | 寸法 | 容量 |
|---|---|---|
| `kyoyo-card.webp` | 900×300 | 23KB |
| `healthy-card.webp` | 900×300 | 14KB |
| `teizan-card.webp` | 900×300 | 50KB |
| `history-card.webp` | 900×300 | 33KB |

```
ffmpeg -i もとの写真.png -vf "crop=941:314:0:511,scale=900:-2" -c:v libwebp -quality 72 出来上がり.webp
```

切り出す高さ（上の例の `511`）は会ごとに変えています。人が写っている高さが
違うためです。切り出したら必ず目で見て、**人の顔が切れていないか**確かめてください。

### 道筋の先頭のスラッシュを外さないこと

`bunkakai.html` では、写真の道筋をこう書いています。

```html
<span class="kaiPick__bg" style="--kai-photo:url(/assets/kai/kyoyo-card.webp)"></span>
```

**先頭の `/` は消さないでください。** この変数を使うのは `css/page.css` の側で、
ブラウザは変数の中の相対パスを「その変数を使ったスタイルシート」から数えます。
`assets/...` と書くと `/css/assets/...` を探しにいって、写真が出ません
（実際にそうなり、しばらく気づけませんでした）。

## 大きさと形式

**縦長（9:16 くらい）、長辺 1600px 前後、1枚 500KB 以下**を目安にしてください。

ストーリーは画面いっぱいに出る作りなので、**縦長でないと上下が切れます。**
横長の写真しか無いときは、中身が真ん中に寄っているものを選んでください。

**形式は WebP に揃えています。**お預かりした PNG は1枚 1.8〜2.9MB ありました。
WebP にして 85〜237KB です。会員は70代が中心で通信環境もまちまちなので、
そのまま置かないでください。JPEG で置く場合は、`kai-*.html` の `<img src="...">` の
拡張子も直してください。

変換は次のようにしています。

```
ffmpeg -i もとの写真.png -vf "scale=900:-2" -c:v libwebp -quality 80 出来上がり.webp
```

## 写真が届くまでのあいだの下地

`kai-*.html` の `<div class="slide__photo" style="background-image:url(data:image/webp;base64,...)">`
に、**幅18pxまで縮めてぼかした版**をデータURIで埋め込んであります（1枚 200バイト前後）。
写真が届くまでのあいだ、真っ白のところに文字だけが浮くのを防ぐためのものです。

写真を差し替えたら、こちらも作り直してください。

```
ffmpeg -i もとの写真.png -vf "scale=18:-2,gblur=sigma=1.2" -c:v libwebp -quality 44 下地.webp
base64 -w0 下地.webp
```

## 文字が写真に沈むとき

ストーリーの1枚目は、**写真がはっきり見えること**を先に取っています
（ベールはごく薄く、写真は7〜8割そのまま見えます）。そのぶん文字は写真に直接
載せず、`.heroCard` という白い紙のカードに載せています。各回のカードと同じ作りです。

濃さを変えたいときは `css/story.css` の `.slide--hero .slide__photo::after`（ベール）と
`.heroCard`（カードの地の濃さ）を見てください。上ぶちと下ぶちだけベールを濃く
してあります。ストーリーの名前と、下の「お申し込み・お問い合わせ」の帯が乗るためです。

四つの札（`bunkakai.html`）のほうは白い字を写真に直接載せているので、
`.kaiPick__bg` の深緑の幕と `.kaiPick__text` の影で読ませています。

## 2枚目より後ろの絵

各回のカードの絵は写真ではありません。**内容に合わせて描き起こした svg** が
HTMLに直接埋め込んであります。外の画像は借りていません。
描き替えるときは `css/story.css` ではなく、HTMLの `<svg class="ses__svg">` を直します。
