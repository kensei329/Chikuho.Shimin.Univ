# 筑豊市民大学 ホームページ

福岡県田川市の筑豊市民大学のウェブサイトです。ビルドもサーバー側の処理も要りません。
HTML・CSS・JavaScript を置いてあるだけで、そのまま動きます。

## いちばん大事な決めごと

**スマートフォンの画面だけを作っています。**

本文は幅 520px の縦長の柱を基準に組み、PC で開いたときはその柱を画面の中央に置きます。
デスクトップ向けの別レイアウトはありません。上に固定したヘッダーと、下に固定したタブバーで
行き来する、アプリのような作りです。

会員は70代が中心です。**本文 17px・行間 1.95・タップできる領域は 44px 以上**を守ってください。
ここを縮めると、いちばん読んでほしい人に読めなくなります。

  最初から出さないためです
- **解説** … そのカードの `.card__sheet` の中身を下から開きます。件数は出していません
- **シェア** … 端末の共有シートを呼び、出せない環境ではリンクを写します

## 分科会（ストーリー）

`bunkakai.html` は**四つの札だけ**です。前置きも、あとに続く節も置いていません。
開いてすぐ、どれかを選べる状態にしてあります。

札の中の「ストーリーを見る」は琥珀色で塗ってあります。以前は「見る ›」という小さな文字
でしたが、押せるものだと気づかれませんでした。ロゴの三色にオレンジが入っているので、
深緑の上でも色は浮きません。文字は白ではなく濃い茶を載せています（琥珀の上に白だと
明るすぎて読みにくいため）。

会ごとに1ファイル。**紹介2枚 ＋ その年の回数ぶん ＋ お申し込み1枚**で、
教養講座とヘルシーエイジングが11枚、低山に登ろうと歴史を辿る会が12枚です。

1. 会の名前・回数・募集人数（**お預かりした写真**を画面いっぱいに）
2. どんな会か（案内文の文言そのまま）
3. 〜 第N回。1回ぶんを1枚に。日付・時間・内容・講師
4. お申し込みボタン

**写真は1枚目だけ**で、`assets/kai/` に置いてあります（差し替え方は
`assets/kai/README.md`）。**2枚目から先には絵を置きません。**

以前は回ごとの内容に合わせた svg の挿絵を埋めていましたが、日程を読む
ところに絵があると見るものが二つになり、どちらを追えばよいか迷う、という
ことで全部外しました。いまは無地の上に紙のカードが一枚だけ乗ります。
足したくなったときは、この経緯を踏まえて決めてください。

体裁は `css/story.css` の下のほうの `.slide--hero` `.slide--ses` まわりです。
枚数を増やし減らししても、上のゲージは `js/story.js` が数を合わせます。

5秒で自動的に次へ進みます。押しっぱなしで止まり、上の停止ボタンでも止まります。
動きを減らす設定の環境では、はじめから自動送りをしません。

下の帯には**入力欄を置いていません。**届く先の無い入力欄は、事務局に連絡したつもりに
させてしまうためです。代わりに申し込みフォームへのリンクを置いています。

## 会の呼び名と、申し込みフォームの value

表に出る呼び名は、案内文にそろえて次の四つに統一しています。

**教養講座 ／ ヘルシーエイジング ／ 低山に登ろう ／ 歴史を辿る会**

ただし `index.html` の申し込み欄のチェックボックスだけは、`value` を**古いまま**に
してあります。

```html
<input type="checkbox" name="entry.939298798" value="歴史をたどる会">
<span class="pick__text"><b>歴史を辿る会</b>…</span>   ← 表に出るのはこちら
```

| 表に出る名前 | 送っている value（Googleフォーム側の選択肢） |
|---|---|
| 歴史を辿る会 | `歴史をたどる会` |
| ヘルシーエイジング | `ヘルシー健康講座` |
| 低山に登ろう | `低山山登り` |
| 教養講座 | `教養講座` |

Googleフォームのチェックボックスは、**選択肢に無い文字列を送るとその送信がまるごと
弾かれます**。value だけ先に直すと、申し込みが一件も届かなくなります。

そろえるときは、**先に Googleフォーム側の選択肢を書き換えてから**、この value を
直してください。順番を逆にしないこと。

## PC で見たときの、柱の外の両側

柱は 520px です。スマートフォンに合わせた幅なので、PC で開くと左右に地色が残ります。
そこに二つの帯を出しています。**幅 940px 以上で、指ではなく矢印で操作している画面**
だけです（`@media (min-width: 940px) and (pointer: fine)`）。

| どちら | 中身 |
|---|---|
| 左 | サイトマップの木 |
| 右 | このページの案内（あるときだけ）＋ お申し込み |

木の並びは **ホーム → 理念 → 活動・分科会 → 年間予定** です。

```
ホーム
理念            ← 明朝でひとまわり大きく。上に区切りの線
活動
 ├ 村田 喜代子 …（katsudo.html#murata へ直に）
分科会
 ├ 教養講座 …
年間予定
 └ 5月〜3月（11か月。3つずつ横に並べる）
```

月は `nenkan.html#m11` のように、その月へ直に飛びます。`nenkan.html` の
`<li class="mo" id="m11">` が行き先です。**id を消さないでください。**

月を指して開くと、その月まで一気に飛ぶので手前の月は一度も画面に入りません。
`js/nenkan.js` の出てくる動きは画面に入ったときしか働かないため、そのままだと
透明のまま残ります。指して開いたときだけ全部出す手当てを入れてあります。

## 申し込みフォーム

**Google フォームの URL は、サイトのどこにも出しません。**埋め込みも、
「別の画面で開く」リンクも、もうありません。見た目は自前のフォームで、
送り先は同じサイトの `/api/join` です。

```
画面のフォーム  →  /api/join（このサイトのサーバー）  →  Google フォーム
```

■ なぜ間に一枚はさむのか

ブラウザから Google へじかに投げる方式は、二つの点で行き詰まりました。
一つは、中身が一字一句正しくても Google が 400 を返していたこと
（原因はフォーム側の「メールアドレスを収集する」設定で、あれは設問ではなく
必須欄を勝手に描くため、外から埋める手立てがありません。いまは切ってあります）。
もう一つは、通ったかどうかが読めないこと。Google は別ドメインからの読み取りを
許さないので、弾かれても画面には「受け付けました」と出てしまいます。

サーバー同士のやりとりならブラウザの制限がかからず、Google の返事も読めます。
**本当に届いたと確かめてから、はじめて受付の画面を出します。**
会員の多くは 70 代です。申し込んだつもりで届いていない、がいちばん困ります。
迷ったときは「成功した」と言わない側に倒してください。

| 場所 | フォームの置き方 |
|---|---|
| ホーム `#join` | 本文に、そのまま置いてある |
| 全9ページ 右の帯（幅1180px以上） | 同じフォームをもう一枚 |
| 分科会のストーリー・活動の締め・年間予定のボタン | `/#join` へ渡すだけ |

同じフォームが1ページに何枚あっても動きます。`js/home.js` は id ではなく
`<form>` の中を辿って部品を見つけるので、それぞれ独立して働きます。

■ 送るときの決まりごと

- 入力欄の `name` が、そのまま Google 側の `entry.NNN` です
- **チェックボックスは、選択肢に無い文字列を送るとその送信がまるごと弾かれます。**
  `value` を直すときは、必ず先に Google フォーム側の選択肢を書き換えてください
- 生年月日は任意。年・月・日がそろったときだけ送ります（半端だと日付として
  組み立てられません）。年の初期値は「いまから60年前」をその場で数えています
- 確認事項は、画面では1つのチェックですが、フォーム側では2つの選択肢です。
  送るときだけ2つに戻します

■ 悪用への構え（`api/join.js`）

この入口は誰でも叩けます。放っておくと偽の申し込みで事務局の受信箱が埋まります。

1. 自分のサイトから来たものだけ通す（Origin / Referer / Sec-Fetch-Site）
2. 連射を止める。同じ相手は10分8通・1時間20通、入口ぜんたいで10分30通・1時間60通
3. 人には見えない欄（`kakunin`）を1つ置き、埋まっていたら機械とみなす

数える相手は `x-vercel-forwarded-for` / `x-real-ip` で見ます。`x-forwarded-for` は
送り手が先頭に好きな値を足せるので、それだけを見ていると数え直しにされます。

**高齢の会員に謎かけ（CAPTCHA）はさせません。**手間を増やさずに打てる手は
ここまで、という判断です。

`#` で飛んだときに見出しがヘッダーの下へ潜らないよう、`.page section[id]` に
`scroll-margin-top` を入れてあります。

受け付けはフォームのみです。電話番号とメールアドレスはページに載せていません。

## 設立理念

`rinen.html` は、6つの場面が順に流れるアニメーションです。

1. 筑豊市民大学／設立理念（大きくなりながら現れる）
2. わたしが変われば、周りが変わる（左から右へ流れる）
3. 周りが変われば、地域が変わる（下から上へ立ちのぼる）
4. 地域が変われば、社会が変わる（一点から広がる）
5. 一人の灯が仲間を呼び、まちになり、社会へ広がる情景（線画）
6. 設立理念の全文が、下から上へ 14 秒かけて流れる

場面が進むごとに空の色が変わり、稜線の灯りが一つずつ増えます。画面を押すと次へ。
`←` `→` でも送れ、空白キーで止まります。

終わりの画面には、はじめから見るほかに **活動 / 分科会 / 年間予定** への行き先を置いて
あります。ここで行き止まりにすると、タブバーを押すしか先が無くなるためです。

**最後の一枚だけは、押すと「送る」ではなく「止まる」**ようにしてあります。会員は70代が
中心で、14秒で読み切れないことがあります。送ってしまうと終わりの画面へ行き、本文へ戻る
手立てが「はじめから見る」しか無くなるためです。もう一度押すと流れが再開します。

本文は、団体からお預かりした設立理念の全文です。改行を句読点でつないでいますが、
**言葉は一字も変えていません。**文言を直すときは、原文の意図を必ず確認してから触ってください。

### 直すときの注意

- **ヘッダーとタブバーは、この舞台の外側にあります。**`.frame` は `top: var(--header-h)`
  と `bottom: var(--nav-h)` で留めてあり、間だけを使います。ここを `100dvh` からの
  引き算に書き換えると、iOS でアドレスバーが伸び縮みするたびにずれます
- `--head` / `--foot` は舞台の中の余白です。`--foot` は稜線を座らせる高さも兼ねています
- 場面の秒数は各 `<section>` の `data-dur`、本文が流れる秒数は `js/rinen.js` の `READ_SEC`
- 書体は、サイトがすでに取り寄せているものに合わせてあります。もとの指定に戻すと、
  この1ページのためだけにもう2書体を取りにいきます

## ファビコンと、SNSに貼ったときの絵

すべて `logo.png` から書き出しています。作り直すときは、ロゴを差し替えてから同じ切り出し
（`logo.png` の x 70–395 / y 130–305、まわりに10%の余白、地は `#F4F5EE`）でやり直してください。

| ファイル | 何に使うか |
|---|---|
| `favicon-tab-16.png` `favicon-tab-32.png` | **パソコンのタブ**（お預かりした「筑大」の絵） |
| `favicon.ico` | `/favicon.ico` を直接取りにくる相手（古いブラウザ、一部のクローラ）。48 の1枚だけ |
| `favicon-48.png` `favicon-96.png` `favicon-192.png` | 検索結果と、その他の場面 |
| `favicon-512.png` | ホーム画面に置いたとき |
| `apple-touch-icon.png` | iOS のホーム画面。180×180、透過なし（透過だと黒く出る） |
| `site.webmanifest` | 上をまとめて宣言している |
| `og.png` | X・LINE などに貼ったときの絵。1200×630 |

**タブと検索結果で絵を分ける方法について、正直なところ。**
X・LINE に貼ったときの絵は `og:image` なので、これは確実に分けられます。
一方、**タブと Google の検索結果は、同じ `<link rel="icon">` を見ています。**
分けられるのは「どの大きさを先に出すか」までで、Google が必ず大きいほうを
選ぶという保証はありません。いまは 16/32 に「筑大」、48 以上にロゴを割り当てて
います。検索結果の絵は、Google が取り直すまで数日〜数週間かかります。

**データURI（base64）で埋め込んではいけません。**Googleはクロールできる実ファイルのURLしか
読まないため、埋め込むと検索結果にアイコンが出ません。

**ファビコンは紋章の一部だけを切り出しています。**ロゴ全体（弧を描く言葉や団体名まで）を
48pxに縮めると、何の絵か分からない塊になります。「開いた本・山・日の出」に絞ってあります。

`og.png` は**中身を真ん中に寄せてあります。**LINEなど正方形に切って出す置き場でも、ロゴが
欠けないためです。透過のまま貼ると黒地で潰れるので、紙色を敷いてあります。X向けに
`twitter:card` は `summary_large_image` にしてあります。

### 決まりごと（CSP）とヘッダー

`vercel.json` で全ページに `Content-Security-Policy` ほかを付けています。
差し込まれた JavaScript は、たとえ紛れ込んでも動きません。

**HTML に `<script>` を直接書いたり、`onclick=` `onerror=` を属性で書いたり
すると動かなくなります。**JavaScript は `js/` の中に置いてください。
どうしても直書きが要るときは、その中身の sha256 を取って `script-src` に
足す必要があります（いま入っているのは、書体を後から効かせる短い一つだけ。
中身を1文字でも変えたら、ハッシュを取り直してください）。

外に許しているのは、書体（fonts.googleapis.com / fonts.gstatic.com）と
会場の地図（www.google.com の枠）だけです。

`google5c7353c4e11c838d.html` は Search Console の所有権確認ファイルです。
**確認が済んだあとも削除しないでください。**消すと所有権が外れます。
`vercel.json` で `cleanUrls` を false にしているのも同じ理由です。true にすると
`/google5c7353c4e11c838d.html` が転送され、確認に失敗します。

**公開URLが変わるとき**は、次を新しいURLに書き換えてください。

1. 各HTMLの `<link rel="canonical">` と `og:url` と `og:image`
2. `index.html` の JSON-LD の `url` と `logo`
3. `robots.txt` と `sitemap.xml`
